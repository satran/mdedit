# MDEdit website

One static page, no build step and no JavaScript. Open `index.html`, or serve the folder (`python3 -m http.server`) to see it with its images.

*   **Publish:** GitHub Pages deploys this folder by itself when it changes on `main` (`.github/workflows/pages.yml`; the maintainer notes `README.md` and `SCREENSHOTS.md` are left out). One-time setup: Settings ▸ Pages ▸ Source "GitHub Actions", custom domain `mdedit.satran.in`, Enforce HTTPS, and a DNS `CNAME` record `mdedit` pointing to `satran.github.io` (DNS only, not proxied, if the DNS is on Cloudflare). `CNAME` in this folder holds the domain. The site must be served from the root of its domain, because the page links to `/img/...` and `/favicon.ico`; any other static host works too.
*   **The domain:** `https://mdedit.satran.in/` is written in `index.html` (canonical, `og:url`, `og:image`, the structured data), `sitemap.xml`, `robots.txt` and `llms.txt`. Change it in those places, and in `CNAME`, if the site lives elsewhere.
*   **The download button:** it points at `https://github.com/satran/mdedit/releases/latest/download/MDEdit.dmg`. `make release` writes that fixed name next to the versioned one (`build/MDEdit.dmg`); attach both to each GitHub release and the button always gets the newest build.
*   **Screenshots:** `img/mdedit-light.png` and `img/mdedit-dark.png` are renders of the real window (2930 px wide, with the window shadow in the picture); `img/og.png` is the 1200 by 628 share image cut from the light one. Replace them when the look changes. The feature images are `feature-{templates-editor,templates-preview,agent-review,focus,fuzzy-find}-{light,dark}.png`; the shot list is in `SCREENSHOTS.md`.
*   **Open source:** the footer, the FAQ answer "Is MDEdit open source?" and the `license` fields in the structured data say MIT. The install answer says the app is notarised: true only for a build made with `make release SIGN=... NOTARY=...`.
*   **The text:** the questions at the bottom are also in the structured data at the top of `index.html`. Keep the two in step when you edit one.
